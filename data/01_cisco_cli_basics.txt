============================================================
คู่มือคำสั่งพื้นฐาน Cisco CLI (IOS / IOS-XE)
หัวข้อ: โหมดการทำงาน, VLAN, IP Interface, การบันทึกค่า
============================================================

1. โหมดการทำงานของ Cisco CLI
------------------------------------------------------------
Cisco IOS แบ่งการทำงานเป็นหลายโหมด โดยแต่ละโหมดมี prompt ต่างกัน

  Switch>                    = User EXEC mode (ดูข้อมูลได้จำกัด)
  Switch#                    = Privileged EXEC mode (ดูและสั่งงานได้ทั้งหมด)
  Switch(config)#            = Global Configuration mode
  Switch(config-if)#         = Interface Configuration mode
  Switch(config-line)#       = Line Configuration mode

คำสั่งเปลี่ยนโหมด:
  Switch> enable                  ! เข้า Privileged EXEC
  Switch# configure terminal      ! เข้า Global Config
  Switch(config)# interface gigabitEthernet 0/1
  Switch(config-if)# exit         ! ถอยกลับ 1 ระดับ
  Switch(config-if)# end          ! กลับไป Privileged EXEC ทันที (หรือกด Ctrl+Z)

เคล็ดลับการใช้งาน CLI:
  - กด Tab เพื่อเติมคำสั่งอัตโนมัติ
  - พิมพ์ ? เพื่อดูคำสั่งที่ใช้ได้ เช่น "show ?" หรือ "interface ?"
  - ใช้ตัวย่อได้ เช่น "conf t", "sh run", "sh ip int br"
  - ใช้ "no" นำหน้าคำสั่งเพื่อยกเลิกค่านั้น เช่น "no shutdown"

2. การตั้งค่าเริ่มต้นของอุปกรณ์
------------------------------------------------------------
  Switch(config)# hostname SW-CORE-01
  Switch(config)# no ip domain-lookup
  Switch(config)# enable secret MyStr0ngPass
  Switch(config)# service password-encryption
  Switch(config)# banner motd # Authorized Access Only #

ตั้งค่า Console และ VTY (Telnet/SSH):
  Switch(config)# line console 0
  Switch(config-line)# password cisco123
  Switch(config-line)# login
  Switch(config-line)# logging synchronous
  Switch(config-line)# exit

  Switch(config)# ip domain-name lab.local
  Switch(config)# crypto key generate rsa modulus 2048
  Switch(config)# ip ssh version 2
  Switch(config)# username admin privilege 15 secret AdminPass123
  Switch(config)# line vty 0 15
  Switch(config-line)# transport input ssh
  Switch(config-line)# login local
  Switch(config-line)# exec-timeout 10 0

3. การตั้งค่า VLAN
------------------------------------------------------------
3.1 สร้าง VLAN
  Switch(config)# vlan 10
  Switch(config-vlan)# name SALES
  Switch(config-vlan)# exit
  Switch(config)# vlan 20
  Switch(config-vlan)# name IT
  Switch(config-vlan)# exit

3.2 กำหนดพอร์ตแบบ Access (ต่อกับเครื่องผู้ใช้)
  Switch(config)# interface range fastEthernet 0/1 - 12
  Switch(config-if-range)# switchport mode access
  Switch(config-if-range)# switchport access vlan 10
  Switch(config-if-range)# spanning-tree portfast
  Switch(config-if-range)# exit

3.3 กำหนดพอร์ตแบบ Trunk (ต่อระหว่างสวิตช์)
  Switch(config)# interface gigabitEthernet 0/1
  Switch(config-if)# switchport trunk encapsulation dot1q
  Switch(config-if)# switchport mode trunk
  Switch(config-if)# switchport trunk allowed vlan 10,20,99
  Switch(config-if)# switchport trunk native vlan 99
  Switch(config-if)# exit

หมายเหตุ: สวิตช์รุ่นใหม่บางรุ่นรองรับเฉพาะ dot1q จึงไม่ต้องใช้คำสั่ง
"switchport trunk encapsulation dot1q" (ถ้าใช้จะขึ้น error ซึ่งไม่เป็นไร)

3.4 คำสั่งตรวจสอบ VLAN
  Switch# show vlan brief
  Switch# show interfaces trunk
  Switch# show interfaces gigabitEthernet 0/1 switchport

4. การตั้งค่า IP Address ที่ Interface
------------------------------------------------------------
4.1 Layer 3 Switch: ใช้ SVI (Switch Virtual Interface)
  Switch(config)# ip routing
  Switch(config)# interface vlan 10
  Switch(config-if)# ip address 192.168.10.1 255.255.255.0
  Switch(config-if)# no shutdown
  Switch(config-if)# exit

4.2 Layer 2 Switch: IP สำหรับบริหารจัดการ
  Switch(config)# interface vlan 99
  Switch(config-if)# ip address 192.168.99.2 255.255.255.0
  Switch(config-if)# no shutdown
  Switch(config-if)# exit
  Switch(config)# ip default-gateway 192.168.99.1

4.3 Router: ตั้งค่า IP ที่ Physical Interface
  Router(config)# interface gigabitEthernet 0/0
  Router(config-if)# description LINK-TO-CORE
  Router(config-if)# ip address 10.0.0.1 255.255.255.252
  Router(config-if)# no shutdown

4.4 Router-on-a-Stick (Inter-VLAN Routing ด้วย subinterface)
  Router(config)# interface gigabitEthernet 0/0
  Router(config-if)# no shutdown
  Router(config-if)# exit
  Router(config)# interface gigabitEthernet 0/0.10
  Router(config-subif)# encapsulation dot1Q 10
  Router(config-subif)# ip address 192.168.10.1 255.255.255.0
  Router(config-subif)# exit
  Router(config)# interface gigabitEthernet 0/0.20
  Router(config-subif)# encapsulation dot1Q 20
  Router(config-subif)# ip address 192.168.20.1 255.255.255.0

4.5 Static Route
  Router(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.2
  Router(config)# ip route 172.16.0.0 255.255.0.0 10.0.0.2

5. การบันทึกและสำรองค่า
------------------------------------------------------------
  Switch# copy running-config startup-config      ! หรือ "write memory"
  Switch# show running-config
  Switch# show startup-config
  Switch# copy running-config tftp:               ! สำรองไปยัง TFTP server
  Switch# erase startup-config                    ! ล้างค่า (ตามด้วย reload)
  Switch# reload

6. คำสั่ง show ที่ใช้บ่อย
------------------------------------------------------------
  show version                 ดูรุ่น, IOS version, uptime
  show ip interface brief      สรุปสถานะ IP และ interface
  show interfaces status       สถานะพอร์ตของสวิตช์
  show mac address-table       ตาราง MAC address
  show ip route                ตาราง routing
  show cdp neighbors detail    ดูอุปกรณ์ข้างเคียง
  show logging                 ดู log ในอุปกรณ์

7. ข้อควรระวัง
------------------------------------------------------------
- ก่อนแก้ค่าบนอุปกรณ์ production ให้สำรอง config ก่อนเสมอ
- ถ้าแก้ค่า interface ที่ใช้ remote เข้ามา อาจทำให้หลุดจากอุปกรณ์ได้
- อย่าลืม "no shutdown" เพราะพอร์ตของ Router จะ down เป็นค่าเริ่มต้น
- ใส่ description ที่ทุก interface สำคัญ เพื่อให้ตรวจสอบภายหลังง่าย
